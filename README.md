## Vue d'ensemble

Ce projet illustre une application fullstack Java / Angular orientée tests, qualité logicielle et automatisation.

Le point fort du dépôt est la couverture de tests:
- tests unitaires
- tests d'intégration
- tests de controllers
- tests BDD avec Cucumber
- scénarios métier documentés dans `features`

## Business case associé

Voir le document de cadrage métier:
- [business_case.md](./business_case.md)

Ce document explique:
- le besoin d'automatisation
- la valeur de la CI/CD
- le rôle des tests dans la qualité
- le lien entre validation, livraison et fiabilité

## Objectif

Montrer qu'une application métier peut être accompagnée d'un vrai socle de validation:
- code fonctionnel
- comportement vérifié
- scénarios métier lisibles
- pipeline d'automatisation

## Ce que le projet démontre

- backend Spring Boot structuré en couches
- frontend Angular organisé par fonctionnalités
- tests de services, controllers, repositories et DTO
- scénarios Cucumber pour valider les parcours métier
- intégration CI/CD via GitHub Actions
- conteneurisation avec Docker

## Valeur métier

Ce projet prouve qu'on ne livre pas seulement une fonctionnalité:
- on la vérifie
- on la stabilise
- on la documente
- on l'intègre dans un flux de livraison propre

## Couverture de tests

Le dépôt contient notamment:
- tests unitaires sur services et entités
- tests sur les controllers REST
- tests d'intégration
- tests des exceptions métier
- scénarios BDD pour les flux utilisateur

## Ce que ce projet montre rapidement

Ce projet montre que le candidat sait:
- structurer une application par couches
- écrire et organiser des tests
- travailler avec JUnit, Mockito et Cucumber
- gérer un pipeline de qualité
- aligner code, validation et CI/CD
