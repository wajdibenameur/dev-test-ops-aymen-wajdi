# Business Case - CI/CD DevOps Automation

## 1. Contexte
Ce projet illustre la mise en place d'une chaîne CI/CD automatisée avec Jenkins, Docker et Kubernetes pour déployer une application Angular.

## 2. Besoin métier
Le besoin est de réduire le travail manuel et de fiabiliser le déploiement:
- déclenchement automatique après un push
- build contrôlé
- déploiement reproductible
- exposition du pipeline et suivi du processus

## 3. Objectif du projet
Démontrer une approche DevOps concrète qui relie le code source, l'automatisation, le conteneur et l'orchestration.

## 4. Valeur pour le métier
Le projet montre:
- une livraison plus rapide
- moins d'erreurs humaines
- une meilleure traçabilité
- un socle de déploiement industrialisé

## 5. Ce que ce projet met en évidence
Même si c'est très technique, il montre une lecture produit importante:
- automatiser un processus
- fiabiliser un parcours de livraison
- rendre l'exploitation répétable
- améliorer le temps de mise en production

## 6. Compétences mises en avant
- compréhension d'un flux de livraison logiciel
- pilotage d'un pipeline de bout en bout
- organisation d'un environnement de déploiement
- articulation entre build, test et release

## 7. Compétences techniques visibles
- Jenkins
- Docker
- Kubernetes / Minikube
- Angular
- Webhooks / Ngrok
- CI/CD
- Ubuntu / VM

## 8. Ce que ce projet montre immédiatement
Ce projet montre que le candidat sait:
- industrialiser un déploiement
- automatiser une livraison
- penser fiabilité et reproductibilité
- parler d'un pipeline comme d'un produit
